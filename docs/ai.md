# TrueSpend AI Feature Architecture & SPEX Technical Guide

This document provides an end-to-end explanation of how **SPEX**—TrueSpend's intelligent financial copilot and interactive animated companion—works across the frontend context builder, spritesheet animation engine, backend LLM router, and human-in-the-loop database action gateway.

---

## 1. High-Level Overview

SPEX combines an **Agentic AI Financial CFO** with an **Interactive Animated Mascot Companion**:
1. **TrueSpend Liquidity Formula**:
   $$\text{Safe-to-Spend Liquidity} = \text{Total Liquid Wallets} - \text{Emergency Buffer} - \text{Investment Reserve}$$
2. **Custom Financial Cycle Lens**:
   All KPIs, historical periods, and burn rates are evaluated across the user's custom payday cycle (`payrolls`), never arbitrary calendar months.
3. **Scoped & Depth-Configurable Context Injection**:
   Users can control which financial domains SPEX analyzes (`all`, `investments`, `transactions`, `wallets`, `budgets`, `debts_goals`, `forecast`) and the response depth (`deep_creative`, `balanced`, `concise`).
4. **Human-in-the-Loop Safety**:
   SPEX never mutates the PostgreSQL database autonomously. Every proposed mutation is returned as a structured approval card in the UI and only executed when the user clicks **Approve** (`POST /api/chat/actions`).

## 2. Real-Time Financial Context Injection (`src/lib/aiContext.ts`)

Every message sent to `POST /api/chat` includes a live deterministic snapshot generated by `buildAiContextSnapshot()`.

### Key Sections of the AI Context Snapshot
1. **`kpis` & `financialPeriodSummary`**:
   - Live `totalLiquidityMad`, `safeToSpendMad`, `bankBalanceMad`, `cashOnHandMad`, `emergencyBufferMad`, `investmentReserveMad`, `dailyAllowanceMad`, `dailyRemainingMad`, `daysUntilPayroll`, and `runwayDays`.
2. **`historicalFinancialPeriods`**:
   - Generated via `generateFinancialPeriodsLedger()`, providing exact opening/closing liquidity, salary income, net living expenses, reimbursable splits, debt repayments, investment deployments, and cash savings rate % for every past and current pay cycle.
3. **`unifiedNetWorthBreakdown`**:
   - Reconciles non-investment cash/savings + live synced investment portfolio (`totalPortfolioValueMad`) + pending receivables minus pending payables.
4. **`investments` (Stocks & Spot Crypto Telemetry)**:
   - Live USD/MAD rate, total portfolio value, unrealized P&L, annual dividend income, Binance Spot/Funding/Earn breakdown, and top held stock/crypto positions with canonical 8-sector tags.
5. **`subscriptions`**:
   - Active and planned recurring commitments (including `every_3_months` gym/insurance cycles, normalized monthly burn, and upcoming renewal dates).
6. **`holisticForecast`**:
   - Deterministic end-of-cycle liquidity projection (`expected`, `best`, `worst`), risk flags, and category burn pace.

## 3. LLM Routing & Resilience (`server/services/ChatService.ts`)

- **Dynamic Model Discovery & Failover**: Queries OpenRouter's live model catalog (`gemini`, `llama-3.3-70b`, `deepseek`) with automatic multi-model fallback and a persistent `.last_working_model` cache.
- **Strict JSON Output Contract**: Returns `{ reply, actions, suggestions }`, sanitized via `extractJson()` so markdown fences never break UI rendering.

## 4. The AI Action Gateway & Pre-Execution Impact Simulator (`server/services/AiActionGateway.ts`)

Before approving a proposed action card in `AIChat.tsx`, users can click **Simulate Impact** (`POST /api/chat/simulate-actions`) to preview the exact deterministic **Before $\rightarrow$ After** delta on:
- **Total Liquid Balance (`totalLiquidityMad`)**
- **Safe-to-Spend (`safeToSpendMad`)**
- **Daily Allowance (`dailyAllowanceMad`)**
- **Runway Days (`runwayDays`)**

| Action Type | Key Parameters | Target Service |
| :--- | :--- | :--- |
| `create_transaction` | `amount`, `type`, `source_wallet`, `category`, `notes`, `transaction_date` | `TransactionService.createTransaction` |
| `create_debt` | `amount`, `contact`, `type` (`Receivable` \| `Payable`), `due_date` | `DebtService.processDebt` |
| `settle_debt` | `debtId`, `amount`, `sourceWallet` | `DebtService.processDebt` |
| `upsert_budget` | `category`, `amount`, `year`, `month` | `CategoryBudgetService.upsertBudget` |
| `create_goal` | `name`, `targetAmount`, `currentAmount`, `deadline`, `category` | `GoalService.createGoal` |
| `contribute_goal` | `goalId`, `amount` | `GoalService.contributeToGoal` |
| `update_settings` | `payday`, `emergencyBuffer`, `salary` | `SettingsService.updateSettings` |

## 5. Interactive SPEX Sprite Animation Engine (`SpexSpriteAnimator.tsx` & `SpexCompanionWidget.tsx`)

In addition to the chat interface, SPEX appears as an interactive animated companion powered by the high-resolution `SPEX-spritesheet-v2.webp` (`2264×3113`, 8 columns × 11 rows, `283×283` per frame):

- **9 Choreographed Animation States**:
  - `row 0: idle` (6 frames — gentle breathing & visor blink)
  - `row 1: running-right` (8 frames — rightward flight boost)
  - `row 2: running-left` (8 frames — leftward flight boost)
  - `row 3: waving` (4 frames — friendly greeting wave)
  - `row 4: jumping` (5 frames — celebratory jump arc)
  - `row 5: failed` (8 frames — empathetic slump & recovery)
  - `row 6: waiting` (6 frames — curious head tilt)
  - `row 7: running` (6 frames — energetic cheer)
  - `row 8: review` (6 frames — analytical inspection pose)
- **360° Cursor Gaze Tracking (`row 9` & `row 10`)**:
  - Tracks mouse/touch coordinates across 16 directional angles (`0°` to `337.5°` in `22.5°` increments) when in cursor-follow mode.
